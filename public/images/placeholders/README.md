# Temporary sample photography

These local files are food-only sample photos used while the restaurant’s
original image files are unavailable. They are not photos of 7th Sky and must
not be presented as such. Customer-facing pages label them as temporary sample
photography.

Replace them by adding the restaurant’s approved photos to
`public/images/restaurant/` using the filenames in that folder’s README. The
app will prefer the restaurant photo and retain these local images as fallbacks.
