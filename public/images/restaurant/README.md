# 7th Sky restaurant assets

The supplied new logo and four restaurant photographs are in this folder.
Their existing filenames are intentionally preserved.

| Filename | Intended use |
| --- | --- |
| `wordmark.png` | Transparent extracted wordmark used throughout the application |
| `logo.jpg.jpeg` | Original supplied logo source; preserved unchanged |
| `hero-01.jpg.png` | Homepage slideshow, slide 1 |
| `hero-02.jpg.png` | Homepage slideshow, slide 2 |
| `hero-03.jpg.png` | Homepage slideshow, slide 3 |
| `hero-04.jpg.png` | Homepage slideshow, slide 4 |

Uploaded menu photos and their confirmed menu matches are listed in
`../menu/README.md`. Unmatched menu items retain their existing image paths.

The supplied logo source is a JPEG with a checkerboard background baked into
its pixels. `wordmark.png` is a tightly cropped transparent extraction of its
original lettering and connected ornamentation; the source image remains
unchanged.

The slideshow uses only the four supplied images listed above. They are
displayed from their original files without upscaling or alternate image
fallbacks.
